## Overview

BethINI Pie is a Python-rewritten, fully open-source successor to BethINI, providing a clean graphical interface for optimizing the INI configuration files of Skyrim SE/AE, Fallout 4, Starfield, and Oblivion Remastered. It offers tiered presets from Low to Ultra with explanatory tooltips for every individual setting, allowing both new players and veteran modders to squeeze maximum performance or visual fidelity from their Bethesda installations. A timestamped backup is created automatically before any changes are applied.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **BethINI Pie** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Game Support** | Covers Skyrim SE/AE, Fallout 4, Starfield, and Oblivion Remastered |
| **Optimization Presets** | Low, Medium, High, and Ultra presets tuned per game for balanced results |
| **INI Tooltips** | Every setting includes an explanation of what it controls and its effect |
| **Auto Backup** | Timestamped INI backup created before any changes are written to disk |
